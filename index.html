How instructions work

  • main plays a block once. main[5x] plays five passes.
  • main[90s] and main[1m30s] repeat until that time, then finish the line or the block pass.
  • main[@shift] and main[@shift:3] repeat until that lead marker. main[@end] fills until the lead ends.
  • wait[5s], wait[1m], wait[1m30s], and wait[@shift] are silence.
  • A line @shift in a lead block is a zero-duration marker. {"sfx":"bell"} names a sound id. The server has to approve that id. This page does not include the bell file, and a path or URL is not an id.
  • One track per chapter is the timing lead. Loop repeats the whole follower sequence. Finish says whether a boundary completes the current line or the current block pass.

Audio presets

Root audio is a dictionary of named settings. A track’s audio names one of them, or holds settings inline. Settings are flat: voice, pan, volume_db, reverb, pitch_semitones, speed, resample.

Blocks

Blocks are reused by name, the same way presets are. Every spoken line, marker, and sound used in the download is stored in this file.

Chapters and tracks

A root tracks array is one chapter. chapters holds several. A plan uses one of those shapes.
