# Audio plan composer

[Open the composer](https://ecstasyengineer.github.io/conditioner-composer/).

Build a JSON audio plan, validate it locally in your browser, and download it for `!generate`.

This repository contains the published static site and the shared, pure Python plan validator. The Python runtime loads from jsDelivr. It contains no bot credentials, configuration, or audio assets. The bot bundles Speedwasher IDs `bell`, `clicker`, `gong`, `pop`, `snap`, and `whimper`. The picker lists these IDs; audio files remain on the bot. Additional sound-effect IDs require approval on the receiving server.
